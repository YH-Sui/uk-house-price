# Data directory

Raw and processed data files live here. They are gitignored.

## Download instructions

### UK House Price Index (HPI)
1. Go to https://www.gov.uk/government/statistical-data-sets/uk-house-price-index-data-downloads-november-2024
2. Download the "Average house prices, by property type" CSV
3. Save as `data/uk_hpi.csv`
